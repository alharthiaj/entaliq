# متجر انطلق للطاقة (ENTALIQ ENERGY)

متجر إلكتروني كامل: واجهة متجر عربية/إنجليزية ولوحة تحكم وقاعدة بيانات ودفع إلكتروني.

- **التقنيات:** Next.js 14 و PostgreSQL، والدفع عبر بوابة ميسّر (Moyasar).
- **المحتوى الحالي:** فيه ٥٥ منتجًا تجريبيًا بصور رسمية من الشركات المصنّعة، تستطيع حذفها أو تعديلها من لوحة التحكم.

---

## ما الموجود في المتجر

**واجهة العملاء**
- الصفحة الرئيسية: سلايدر عروض، وبانرات، وصفقة اليوم بعدّاد، والأقسام، والماركات، ورفوف المنتجات، وطلب عرض سعر.
- صفحات الأقسام: فيها تصفية بالتصنيف الفرعي وترتيب بالسعر والخصم والأحدث.
- صفحة لكل منتج: فيها معرض صور، والتقسيط، والمزايا، والمخزون، والمنتجات المشابهة، وبيانات SEO لمحركات البحث.
- البحث والمفضلة والسلة.
- إتمام الطلب: الدفع بالبطاقة (مدى/فيزا/ماستركارد عبر ميسّر)، أو عند الاستلام، أو بتحويل بنكي.
- صفحة تأكيد الطلب، وتتبّع الطلب برقم الطلب والجوال.
- فاتورة ضريبية مبسطة فيها رمز QR بصيغة هيئة الزكاة (المرحلة الأولى).
- صفحات المعلومات: من نحن، والخصوصية، والشروط، والاسترجاع، والضمان، والأسئلة المتكررة.
- عربي وإنجليزي بزر واحد، ويعمل على الجوال.

**لوحة التحكم** (`/admin`)
- **نظرة عامة:** مبيعات اليوم والأسبوع والشهر، ومخطط آخر ١٤ يومًا، وأحدث الطلبات، والمخزون المنخفض، والأكثر مبيعًا.
- **الطلبات:** تصفية حسب الحالة، وبحث، وتغيير الحالة مع ملاحظة، وتأكيد استلام المبلغ، والفاتورة، والتواصل بالواتساب، وتصدير CSV.
  - إلغاء الطلب يعيد الكمية للمخزون تلقائيًا.
- **المنتجات:** إضافة وتعديل وحذف، ورفع صور متعددة بالسحب والإفلات (تُضغط تلقائيًا)، والسعر قبل الخصم، والمخزون، والظهور، وصفقة اليوم، ووصل حديثًا، والمميز.
- **الأقسام:** مع تصنيفاتها الفرعية وصورها.
- **البانرات والسلايدر:** شرائح الواجهة والبانران الجانبيان.
- **التواصل:** طلبات عروض الأسعار، ومشتركو النشرة البريدية (نسخ وتصدير).
- **الصفحات:** تعديل محتوى صفحات المعلومات.
- **الإعدادات:** بيانات المتجر، والسجل التجاري، والرقم الضريبي، وحسابات التواصل، ورسوم الشحن، والشحن المجاني، ورسوم الدفع عند الاستلام، وطرق الدفع، والآيبان.
- **المستخدمون:** نوعان من الصلاحيات (مدير وموظف)، وتغيير كلمة المرور.

## الرفع على الإنترنت (Vercel، بدون أي أوامر برمجية)

المتجر يجهّز قاعدة البيانات بنفسه عند أول نشر، فلا تحتاج تشغيل أي شيء على جهازك.

### ١) ضع الكود في GitHub
١. أنشئ حسابًا في https://github.com إن لم يكن لديك حساب.
٢. أنشئ مستودعًا **خاصًا** (Private) فارغًا باسم `entaliq-store`.
٣. ارفع ملفات المشروع إليه بإحدى طريقتين:
   - بالسحب والإفلات: **Add file ← Upload files**. ارفع الملفات على دفعات، فالحد ١٠٠ ملف في كل مرة.
   - أو اطلب من Claude رفعها لك بعد ربط حساب GitHub به.

### ٢) انشر على Vercel
١. ادخل https://vercel.com وسجّل بحساب GitHub.
٢. اختر **Add New ← Project**، ثم اختر المستودع `entaliq-store`، ثم **Deploy**.
   - النشر الأول ينجح، لكن المتجر يحتاج قاعدة بيانات ليعمل، وهذه الخطوة التالية.
٣. من صفحة المشروع افتح تبويب **Storage**، واختر **Create Database ← Neon (Postgres)**، ثم **Create** و **Connect to project**.
   - هذا ينشئ قاعدة بيانات مجانية ويربطها تلقائيًا.
٤. من تبويب **Deployments** اضغط على آخر نشر، ثم **Redeploy**.
   - في هذا النشر تُنشأ الجداول والمنتجات التجريبية تلقائيًا.

### ٣) أنشئ حساب المدير فورًا
افتح `https://رابط-موقعك/admin`. في أول زيارة تظهر صفحة **"إنشاء حساب المدير"**: أدخل اسمك وبريدك وكلمة مرور قوية.

افعل هذا مباشرة بعد النشر. بعد إنشاء أول حساب تختفي هذه الصفحة نهائيًا، ويصبح الدخول بكلمة المرور فقط.

### ٤) النطاق (اختياري)
من **Settings ← Domains** أضف نطاقك (مثل `store.entaliq.com.sa`)، وأضف سجل DNS الذي يظهر لك عند مزوّد النطاق.

بعدها أضف المتغير `SITE_URL` بقيمة رابطك النهائي من **Settings ← Environment Variables**، ثم أعد النشر.

### متغيرات اختيارية في Vercel
| المتغير | متى تحتاجه |
|---|---|
| `AUTH_SECRET` | نص عشوائي طويل لتأمين الجلسات. اختياري، فالمتجر يولّد مفتاحًا تلقائيًا إن لم تضعه. |
| `SITE_URL` | بعد ربط نطاقك الخاص |
| `MOYASAR_PUBLISHABLE_KEY` و `MOYASAR_SECRET_KEY` | لتفعيل الدفع بالبطاقة |
| `MOYASAR_APPLE_PAY=1` | بعد توثيق Apple Pay في ميسّر |

### ٥) الدفع الإلكتروني (ميسّر)
١. سجّل في https://moyasar.com كمنشأة. تحتاج: السجل التجاري، والحساب البنكي، وتفعيل مدى.
٢. ابدأ بمفاتيح الاختبار (`pk_test_` و `sk_test_`)، وجرّب طلبًا ببطاقة اختبار من وثائق ميسّر.
٣. بعد اعتماد حسابك، ضع المفاتيح الحقيقية (`pk_live_` و `sk_live_`) في Vercel، ثم أعد النشر (Redeploy).
٤. فعّل "الدفع بالبطاقة" من **لوحة التحكم ← الإعدادات**.
٥. **Apple Pay (اختياري):**
   - وثّق نطاقك من لوحة ميسّر.
   - أضف المتغير `MOYASAR_APPLE_PAY=1` في Vercel.

> **الأمان:** يتحقق الموقع من كل عملية دفع مباشرة مع خوادم ميسّر بالمفتاح السري، ويطابق المبلغ ورقم الطلب قبل اعتبار الطلب مدفوعًا. لا يُحفظ أي رقم بطاقة في موقعك.

### ٦) بعد الإطلاق مباشرة
- من **الإعدادات** أدخل: اسم المتجر، والجوال، والواتساب، والسجل التجاري، **والرقم الضريبي** (يظهر في الفاتورة)، والآيبان، ورسوم الشحن.
- استبدل الأسعار التجريبية بأسعارك، أو احذف المنتجات التجريبية وأضف منتجاتك.

## التشغيل على جهازك للتجربة
```bash
npm install
cp .env.example .env    # ثم عدّل القيم
npm run setup
npm run dev             # افتح http://localhost:3000
```

## بدائل الاستضافة
يعمل المشروع على أي استضافة تدعم Node.js 18 أو أحدث، وقاعدة PostgreSQL 13 أو أحدث، مثل:
- Railway أو Render أو DigitalOcean.
- خادم VPS (مثل Hostinger أو مزوّد سعودي).

على أي منها شغّل الأوامر التالية:
```bash
npm install
npm run build
npm start
```
بعد ضبط نفس المتغيرات.

## ملاحظات مهمة قبل البيع الفعلي
- **الفوترة الإلكترونية (فاتورة – المرحلة الثانية):** الفاتورة الحالية مبسطة برمز QR متوافق مع المرحلة الأولى. إذا كانت منشأتك ضمن موجات الربط مع منصة "فاتورة"، تحتاج ربطًا إضافيًا مع الهيئة (عبر مزوّد حلول معتمد).
- **التوثيق:** سجّل متجرك في **المركز السعودي للأعمال** (توثيق المتاجر الإلكترونية)، وأضف رقم التوثيق في الإعدادات.
- **صور المنتجات:** الصور الحالية من المواقع الرسمية للشركات المصنّعة. تأكد من موزّعك أنك مخوّل باستخدامها، أو استبدلها بصورك.
- **الشحن:** حاليًا رسوم ثابتة مع حد للشحن المجاني. ربط شركة شحن (سمسا أو أرامكس أو سبل) لإصدار البوالص آليًا تطوير إضافي.
- **الطلبات غير المدفوعة:**
  - الطلب بالبطاقة يحجز الكمية من المخزون لحظة إنشائه.
  - إذا لم يكمل العميل الدفع، ألغِ الطلب من لوحة التحكم لتعود الكمية.
- **النسخ الاحتياطي:** Neon يحتفظ بنسخ تلقائية. يمكنك أيضًا تصدير الطلبات CSV من لوحة التحكم.

## بنية المشروع
```
app/(store)/        صفحات المتجر
app/admin/          لوحة التحكم
app/api/            واجهات الطلب والدفع ورفع الصور

lib/                قاعدة البيانات، المصادقة، الطلبات، الترجمة
db/schema.sql       جداول قاعدة البيانات
db/setup.mjs        التهيئة والبيانات الأولية
```
